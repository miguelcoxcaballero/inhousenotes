# v5.14.0

Reloading now always opens the latest published version. The app checks which version is live on GitHub, bypassing every cache, and if a newer one is out it refreshes itself once. It never does this while a document is open; that waits until you come back to the app. Offline, the saved copy still opens as before.

Folders look like real manila folders: the tab is cut from the back of the folder in the same colour, the tops of the sheets show above the cover, and the board has a faint paper grain. The cover shows only the folder's name, with more room for it, and no "Folder" label. This is a web only release; the Android app picks it up automatically.
