# Inhouse Notes v5.11.56 · A and B

Download APK recovery link.

At the user’s explicit request, Android 1.0.16 (versionCode 17) is now offered in both A and B. This promotes the exact previously published and verified APK; its URL, signing certificate, SHA-256, size, release date and existing A metadata are unchanged.

Older installed APKs receive the web recovery link when they reopen Notes. If their installer closes, Download APK opens the release in the browser; open that file from Downloads and install over the existing app. The installed app version confirms the update on the next launch when an attempt has been recorded.

The shared native cancellation, retry and self-update flow passed on an Android 15 emulator. This release has not been tested on a physical Android device. The reported device’s old installer handoff has not been reproduced locally.
