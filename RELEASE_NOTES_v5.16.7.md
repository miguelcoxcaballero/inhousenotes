# v5.16.7

- Folder opening now expands the folder to fill the content viewport in one direct zoom. Closing reverses the same motion, including nested folders and breadcrumb navigation.
- A moderate ease-in/out replaces the abrupt lateral movement. The lid stays below a quarter-turn and the content fade only completes the transition after the zoom is visible.
- Returning to a folder preserves its scroll and uses the actual card position after resizing. Rapid navigation cleans up animation layers and hidden cards; reduced-motion preferences remain respected.

Web and Android-hosted app assets updated. The signed Android APK remains 1.0.21; channel catalogs are unchanged.
