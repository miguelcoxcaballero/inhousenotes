# v5.13.1

Home is back to Recents, Starred and Shared, each as a row with a "See all" link to its own tab. Folders live in Files.

Folder covers: long names no longer run under the ⋮ menu, which now sits in the bottom corner, and the name shrinks to fit long words instead of breaking them. The small inhouse notes logo is gone from the covers.

Folder colours are calmer at night, less saturated and darker, so they no longer glare, and yellows stay a clean honey or gold in both themes instead of turning greenish or brown. The opened folder at night sits on a warm near-black. This is a web only release; the Android app picks it up automatically.
