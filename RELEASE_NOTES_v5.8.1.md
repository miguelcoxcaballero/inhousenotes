# Inhouse Notes v5.8.1

This patch publishes the Android companion for the faster startup work in v5.8.0.

- Publishes the signed Android 1.0.8 APK as a versioned GitHub release.
- Points both the in-app updater and the website download button to the verified release asset.
- Activates the mandatory update only after the APK is publicly downloadable.
- Includes the immediate first frame and home shell, matching light/dark launch colours, and pull-to-refresh improvements for tablets from v5.8.0.
