# Inhouse Notes v5.2.2

This patch introduces a cleaner, fully responsive sharing sheet.

- The share modal now uses a clearer visual hierarchy inspired by modern Google sharing flows while retaining Inhouse Notes typography, orange accent, surfaces, and rounded geometry.
- Mobile layouts use a safe bottom sheet with independently scrollable content and controls sized for touch.
- The invite row becomes a deliberate two-row layout on phones, preventing the Send button from overflowing outside the modal.
- People, roles, general link access, and the final copy action are separated into readable sections.
- General access now explains whether a link is restricted, viewable without sign-in, or editable after sign-in.
- The Copy link button keeps its icon and styling after loading or error feedback.
- Loading placeholders follow the same responsive layout and no longer occupy space behind the finished content.
