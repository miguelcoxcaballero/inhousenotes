# v5.13.2

PDFs that are not A4 now show in their real shape. A landscape PDF keeps the sheet's width and gets shorter; a very tall one keeps the height and gets narrower. Each one stays centred in the same A4 space, so the grid keeps its rows and columns.

Folders are now exactly the size of a sheet, including on phones, where they share the three-column grid with notebooks. This is a web only release; the Android app picks it up automatically.
